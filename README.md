# Halo Studio

Halo Studio is a pattern editor for Phantom Flow POV devices.

## Download

Download and run:

`HaloStudioSetup-1.0.0.exe`

This Windows installer includes Halo Studio, example patterns, example images, Start Menu shortcuts, a desktop shortcut, uninstall support, and `.halostudio` file association.

## Windows Support

Halo Studio currently supports Windows 10 and Windows 11, 64-bit.

## Note

Windows may show a warning because this early installer is not code-signed yet. Choose **More info** and **Run anyway** if you trust this download source.
